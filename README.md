# ALISS - Accessible Living Support System with Intelligent Assistance

## Overview
ALISS is a project designed to provide accessible living support for individuals through intelligent assistance. The system uses advanced technology to help users manage their daily activities, ensuring a better quality of life.

## Features
- Assistive task management
- User-friendly interface
- Intelligent scheduling
- Notification and reminder system
- Multi-platform support

## Getting Started
### Prerequisites
Before you begin, ensure you have met the following requirements:
- [Node.js](https://nodejs.org/) v14 or higher
- [Git](https://git-scm.com/) installed on your machine
- Access to a PostgreSQL database

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/mtoanchoicode/ALISS-Accessible-Living-Support-System-with-Intelligent-Assistance.git
   ```
2. Navigate to the project directory:
   ```bash
   cd ALISS-Accessible-Living-Support-System-with-Intelligent-Assistance
   ```
3. Install NPM dependencies:
   ```bash
   npm install
   ```
4. Create a `.env` file in the root directory based on the provided `.env.example`. Fill in the necessary environment variables.
5. Run the database migrations:
   ```bash
   npm run migrate
   ```
6. Start the application:
   ```bash
   npm start
   ```

## Usage
- After starting the application, navigate to `http://localhost:3000` in your web browser to access the platform.
- Create a user account to begin using the features of ALISS.
